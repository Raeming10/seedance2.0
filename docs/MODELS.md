# 视频模型

默认 MiniMax H3（`minimax`）：参考模式优先用于保持人物身份与场景元素，按官方六段结构编写提示词；完整阅读 [H3 reference 指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt) 和 [基础指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/base-en.txt)。本地参数边界见 `guide minimax`。

保留 Google Veo 3.1（`veo`）供明确选用；Flare Medium（`flare`）负责人物身份图与必要的构图图。Seedance 视频模型已从可调用目录、请求校验和插件安装包中移除。

默认模型是用户的创作偏好，不代表对所有模型做过同条件质量评测。定价以预检和供应商账单为准；预检不产生生成费用。
