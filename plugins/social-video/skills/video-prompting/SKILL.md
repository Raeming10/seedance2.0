# Compile the directed story

Use this inside [create-video](../create-video/SKILL.md), or alone for prompt-only work. Prompt-only work does not require credentials, service startup or paid generation. LAUNCHER is `../../scripts/studio.js` resolved relative to this file; bundled offline guides are under `../../runtime/docs/guides`.

1. Lock original plot and exact dialogue, with speakers and order. Separate tagline/narration from speech. A viral edit, target duration or different template is not permission to rewrite, translate, cut or add lines. If the requested duration is clearly longer than the complete source needs, independently compile prompts for its natural duration and tell the user the estimate; no length-only confirmation gate. Do not compile invented filler. Fast pacing means compressing screen time through efficient shot construction and editing while telling the entire supplied story clearly: overlap dialogue with relevant action, remove redundant coverage and retain causal links, key reactions and every supplied line. It does not mean arbitrary rapid cuts or omitting story information.
2. Direct the source: each shot gets a source beat, scale/viewpoint, entering state, blocking/action/reaction, motivated camera/cut, sound and duration. Reference mode permits new composition and movement; do not impose a still portrait or call-camera constraints. Consider a call only for an explicit video-call request.
3. Read the selected runtime guide and `guide video-prompting`. Default H3 (`minimax`) reference mode; Veo 3.1 remains available. Seedance is removed. For H3, read the **entire official ref-en.txt plus base-en.txt**, linked in `guide minimax`; a base-only read or excerpt is not enough. Follow the official six-section Ref2VA format and speaker/timing rules. Format the sections as text inside fal's `prompt`; do not discard them or send unsupported JSON fields.
4. Map real reference assets to roles. Use separate clean identities and, if needed, a people-free location. Do not automatically generate an all-cast tableau or first-frame still for a reference-mode shot. Explicit composition anchors are optional and shot-specific; identities are reusable and pose-independent. Discard/repair a reference with duplicate subjects or transferred attributes before the video phase.
5. Write `subject_definitions`, `summary`, `retention_analysis`, `detailed_description`, `overall_soundscape`, `non_diegetic_music` in order for H3 reference mode. Bind fal `Image 1`, `Video 1`, `Audio 1` array order to the stable official labels in text. No phantom assets or voices inferred from portraits. For frame modes use the base guide's frame alignment and three fields instead.
6. For each shot describe composition, who stands/sits where, visible changes, motivated motion with useful direction/speed/amplitude, synchronized sound and **exact source words**. Maintain speaker IDs in actual vocal-event order. Cuts use source-local time. Don't independently split every line into another static head shot, or fill unused model seconds with repetition. No subtitles/UI/logo inside generation prompts; use the actual existing rendering components later.
7. Save the role map, source lock, timing and prompt audit. Compare all dialogue tags to the source before paying; production beat validation alone does not inspect provider prompts. Check new-view staging is consistent with earlier shots. Never switch a failed reference shot to text-only, or change the story to explain a generation error.

Review actual output against the shot plan and original words. ASR/frames are limited evidence; retain an explicit review-draft label without continuous playback/listening. Existing generated errors are not authorization for script changes or unlimited reruns.

Preserve the generated footage’s native soundtrack (dialogue, ambience, effects and any generated score). Do not add the kit’s bundled background music or a replacement music bed. Set `music: false` for all formats unless the user explicitly requests additional music later. Append the supplied library CTA as-is, including its own audio.
